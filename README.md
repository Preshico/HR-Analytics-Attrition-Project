# HR Employee Attrition Analytics Project
# Project Description

This project explores employee attrition patterns using IBM HR Analytics Employee Attrition dataset. The analysis was conducted using Python for data exploration and statistical analysis, and Power BI for interactive dashboard development.

The objective was to identify the key factors associated with employee turnover and provide data-driven recommendations that can supprt employee retention strategies.

# Key areas analyzed include:
Attrition trendss and overall turnover rate. 
Department and job role performance. 
Employee age and income patterns. 
Overtime and business travel impact. 
Work-life balance analysis. 
Correlation analysis among HR variables. 

The Project combines exploratory data analysis (EDA), Statistical interpretation, and business intelligence reporting to transform HR data into actionable insights.

# Tools Used
Python (Pandas, Numpy, Matplotlib, Seaborn). 
Power BI. 
DAX. 
Statistics. 

# Key Findings
Overall attrition rate was 16.1%. 
Employees working overtime showed significantly higher attrition rates. 
Younger emoloyees were more likely to leave the organization. 
Employees who left generally earned lower salaries than those who stayed. 
Sales recorded the highest attrition rate among departments. 
Poor work-life balance was associaed with increased employee turnover.
